# PRODIGY_WD_02
## Stopwatch
This is a simple Stopwatch Web Application built using HTML, CSS, and JavaScript.
It allows users to start, stop, reset, and track elapsed time with a clean and responsive user interface.

## Features
 Start / Stop the stopwatch
 Reset to clear the timer
 Track elapsed time in minutes, seconds, and milliseconds
 Responsive design – works on desktop and mobile
 Minimal and modern UI

 ## Tech Stack
HTML5 – Structure
CSS3 – Styling and responsive design
JavaScript (Vanilla) – Stopwatch functionality (start, stop, reset, time calculation)

## Project structure
Stopwatch/
│── index.html     # Main HTML file
│── style.css      # Styling (CSS)
│── script.js      # Stopwatch logic (JavaScript)
│── README.md      # Documentation
